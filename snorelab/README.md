# 꿀잠 Lab V0.1 테스트판

서버 없이 Android 기기 내부에서만 수면 소리를 녹음·분석하는 코골이 검증용 앱입니다.

## V0.1 기능
- 화면이 꺼져도 foreground microphone service로 수면 측정
- 테스트 기간 동안 밤 전체 AAC/M4A 녹음 선택 가능
- 1초 단위 음향 특징 및 코골이 후보 점수 기록
- 후보 구간 WAV 저장(후보 직전 약 3초 포함)
- 후보 타임라인 및 음원 재생
- 사용자가 `코골이 / 코골이 아님 / 애매함`으로 수동 검토
- 날짜별 기록 삭제 또는 음원만 삭제하고 분석 패턴 유지
- 개발자 ZIP 내보내기: 분석만 / 후보 음원 포함 / 전체 음원 포함

## 개인정보 원칙
- 회원가입·로그인 없음
- 이름·이메일·전화번호 등 개인정보 입력 없음
- 자체 서버 없음
- 자동 업로드 없음
- 테스트판에는 INTERNET 권한 없음
- 내보내기는 사용자가 직접 실행할 때만 로컬 ZIP 파일 생성

## 첫 야간 테스트 권장 설정
- 감지 민감도: 65
- 전체 녹음: ON
- 후보 WAV: ON
- 휴대폰: 머리에서 약 30~80cm, 충전 연결 권장

아침에 후보 음원을 듣고 가능한 구간을 검토한 다음 `분석 + 후보 음원` ZIP을 내보내 분석에 사용합니다. 후보를 놓친 것으로 의심되는 경우에만 `전체 녹음까지 포함`을 사용합니다.

> 이 테스트 앱은 의료기기가 아니며 수면무호흡증 등 질환을 진단하지 않습니다.
